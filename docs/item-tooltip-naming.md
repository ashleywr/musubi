# Item Tooltip Naming

Naming rule for Musubi tooltips:

- Keep culturally central terms in Japanese when they are part of the item's identity.
- Use short plain-English summary lines as the always-visible tooltip text.
- Put gameplay details in the Shift-expanded section.
- Show the Japanese name in the Shift section when the item has one.

Current keep-as-Japanese terms:

- Tama
- Gohei
- Shimenawa
- Shinboku
- Marudai
- Itomaki

Current English-facing names:

- Silk Thread
- Charged Silk Thread
- Spinning Wheel
- Offering Box
- Weaving Loom
- Silk Skein
- Fiber Bundle
- Woven Cloth
- Enchanted Cloth
